
## Cloth Store Management System

This project is a console-based Cloth Store Management System developed using Python and MySQL. The program helps manage basic store operations such as maintaining cloth item records, storing customer purchase details, and tracking monthly sales information. It automatically creates the required database and tables, and provides a menu-driven interface for entering and retrieving data. Users can add new items, view item details using item codes, record customer transactions, store sales data, and view frequent buyers based on purchase date. The system demonstrates basic database connectivity, data storage, and retrieval using Python with MySQL.
